# Плагин: вставить скриншоты

Вставляет три скриншота (WhatsApp Web, Telegram Web, iPhone) в серые прямоугольники
`img:whatsapp`, `img:telegram`, `img:iphone` на слайде «10 · Нақты жұмыста».
Картинки: `tools/figma-defense-plugin/img/`.

Figma для компьютера → Plugins → Development → Import plugin from manifest… →
`manifest.json` → запустить «AI Fraud Detector — screenshots». Работает за секунду.
