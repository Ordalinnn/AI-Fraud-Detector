# Плагин: обновить презентацию к защите

Один запуск обновляет презентацию «AI Fraud Detector — НОУ қорғауы» в Figma по плану
из [`docs/presentation_update_kz.md`](../../docs/presentation_update_kz.md):

- светлая цветовая гамма (как на сайте);
- актуальные цифры: 5 моделей + стекинг, 94,7 %, новые примеры расчётов;
- 5-я модель на слайде «Жүйе қалай жұмыс істейді»;
- новые слайды «Стекинг: есептеу мысалы» и «Шынайы өмірде тексеру»;
- запасные слайды переносятся в раздел «Қосымша» и скрываются при показе;
- заметки докладчиков с таймингом (≈ 6 мин 50 с).

## Как запустить (≈ 1 минута)

1. Скачайте папку `tools/figma-defense-plugin` (файлы `manifest.json` и `code.js`).
2. Откройте презентацию в **приложении Figma для компьютера**: в браузере свои плагины
   запускать нельзя.
3. Для надёжности: **File → Save to version history**.
4. Меню **Plugins → Development → Import plugin from manifest…** → выберите `manifest.json`.
5. **Plugins → Development → AI Fraud Detector — defense update**.
6. Внизу появится сообщение «Готово: … изменений». Если какие-то правки не нашлись,
   сообщение перечислит их — пришлите его, исправлю.

Отменить всё: Ctrl+Z или вернуться к сохранённой версии в истории.
Повторный запуск безопасен: новые слайды не дублируются, тексты не меняются второй раз.
