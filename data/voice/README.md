# Записи для проверки голосового режима

Скрипт `scripts/eval_speech.py` проверяет на этих записях две вещи:
1. насколько точно речь переводится в текст;
2. **главное**: совпадает ли вердикт «мошенничество / нет» по распознанному тексту с вердиктом по настоящему тексту.

## Что записать (20–30 записей)

- Примерно поровну **казахский** и **русский**, по желанию несколько английских.
- Примерно поровну **«мошеннических»** (вы читаете сценарий мошенника: «служба безопасности банка, назовите код…») и **обычных** («привет, я буду через 10 минут», «урок перенесли на пятницу»).
  Обычные записи нужны, чтобы проверить, не создаёт ли распознавание ложных тревог.
- Записывайте **как в жизни**: телефон на громкой связи, второй телефон или ноутбук пишет. Несколько записей сделайте с шумом (улица, телевизор).
- Записывайте только тех, кто **согласен**. Аудиофайлы по умолчанию не попадают в git (см. `.gitignore`).

## Как оформить

1. Положите файлы в эту папку (`.wav`, `.mp3`, `.m4a`, `.ogg`, `.opus`).
2. Для каждого файла добавьте строку в `manifest.csv`:

| Колонка | Что писать |
|---|---|
| `file` | имя файла, например `kk_fraud_01.m4a` |
| `text` | **точно** то, что сказано (дословно, как есть) |
| `label` | `1` — мошенничество, `0` — обычный разговор |
| `language` | `kk`, `ru` или `en` |

## Как запустить

```bash
pip install -r requirements.txt
python scripts/eval_speech.py
```

В первый раз скачаются модели (около 0,6 ГБ). Результат появится в `reports/speech_evaluation/summary.md`.
Сравниваются три варианта:
- `baseline` — голосовой режим в первой версии;
- `improved` — текущий: казахская модель, подсказка словаря, выравнивание громкости;
- `improved_noprompt` — то же без подсказки словаря. Этот вариант показывает, не вызывает ли сама подсказка ложных тревог.

Метрики:
- **WER / CER** — доля ошибок в словах и буквах (меньше — лучше). Для казахского честнее смотреть на CER: одно неверное окончание делает ошибочным всё длинное слово.
- **Fraud verdict correct** — доля записей, где система правильно определила, мошенничество это или нет.
- **Same verdict as true text** — как часто ошибки распознавания *не* меняют вердикт.
- **False alarms on ordinary** — доля обычных разговоров, которые система ошибочно назвала мошенничеством.
- **Hint leaks** — сколько раз в тексте появилось слово из подсказки, которого на самом деле не говорили.
