# Реальные сообщения команды (казахский и русский)

Жюри попросило отдельно проверить модель на **независимых реальных сообщениях** по каждому языку.
Английская часть уже проверена на открытом корпусе UCI (см. `reports/jury_evaluation/REPORT_RU.md`).
Реальных казахских и русских сообщений в открытом доступе нет, поэтому их нужно собрать самим.
Скрипт для проверки уже готов.

## Что собрать

- **Не меньше 50 сообщений на каждый язык (kk, ru)**, примерно поровну мошеннических (`label=1`) и обычных (`label=0`).
- **Мошеннические:** настоящие SMS, WhatsApp- и Telegram-сообщения, которые получили вы, родственники или знакомые (с их согласия).
  Также подходят **дословные** тексты из официальных предупреждений банков (Kaspi, Halyk), АФМ и полиции.
  Пересказ своими словами не подходит: нужен точный текст.
- **Обычные:** настоящие уведомления банка, доставки, школы, сообщения от семьи (с согласия).
  Именно на них видно, как часто модель ложно блокирует нормальные сообщения.

## Как оформить

1. Скопируйте `team_real_messages_TEMPLATE.csv` в `team_real_messages.csv`.
2. Одна строка = одно сообщение:
   - `text`: текст целиком, в кавычках, если внутри есть запятые;
   - `label`: 1 для мошенничества, 0 для обычного сообщения;
   - `language`: `kk`, `ru` или `en`;
   - `scam_type`: тип мошенничества, если это новый тип, которого нет в обучающих данных;
   - `source`: «моё SMS», «Kaspi, предупреждение от 12.10.2026», ссылка и т. п.;
   - `date_collected`: дата, когда сообщение добавлено.
3. **Анонимизируйте**: имена → `[ИМЯ]`, телефоны → `[ТЕЛЕФОН]`, номера карт и счетов → `[КАРТА]`.
   Домен в ссылке оставьте: он важен для модели.
4. **Не добавляйте эти сообщения в обучение**, пока не получите результат теста. Иначе тест перестанет быть независимым.

## Как проверить

```bash
python scripts/run_jury_evaluation.py --real data/real/team_real_messages.csv
```

Результаты по каждому языку появятся в `reports/jury_evaluation/2_team_real_messages.csv`
и в `results.json` (раздел `section2.real_messages.team_collected`).
Сравниваются старая система из работы и новая.

## Сбор ошибок модели от тестировщиков

Ещё один способ получить реальные сообщения: кнопка **«Это ошибка»**.

- **Расширение:** в окне расширения после проверки есть кнопка «модель ошиблась», а в WhatsApp Web, Telegram Web и Gmail кнопка «Это не мошенничество» под красной пометкой. Внизу окна расширения отмеченные ошибки можно скачать файлом: «⬇️ Скачать CSV».
- **Android:** кнопка «Модель ошиблась» после ручной проверки и «Это не мошенничество» в окне предупреждения. Внизу экрана: «Поделиться файлом (CSV)».
- **Сайт:** кнопка «❌ Нет, ошибка» под результатом, после неё «⬇️ Скачать отмеченные ошибки».

Отметки хранятся только на устройстве тестировщика и никуда не отправляются сами. «Не мошенничество» действует сразу: в расширении и приложении такое сообщение больше не отмечается на этом устройстве (кнопка «Очистить» возвращает предупреждения). На саму модель отметки влияют только после того, как команда соберёт файлы и переобучит её. Файл уже в формате этой папки, где `label` — **правильный** ответ.

1. Попросите тестировщиков (одноклассников, родственников, сотрудников банка) пользоваться системой неделю и отмечать ошибки.
2. Соберите их файлы в `data/real/mistakes/` (эта папка не попадает в Git) и **уберите личные данные**.
3. Запустите:

```bash
python scripts/import_mistakes.py
python scripts/run_jury_evaluation.py --real data/real/collected_mistakes.csv
```

Это сообщения, на которых модель **уже ошиблась**, поэтому точность на них низкая по определению. Они нужны, чтобы увидеть, какие сообщения модель не понимает, и проверить, исправляет ли их новая версия.
