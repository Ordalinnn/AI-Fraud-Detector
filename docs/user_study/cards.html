Исследование: помогает ли AI Fraud Detector распознавать мошенничество

Для проводящего (ученика)

  1. Участники: 16–20 человек, лучше разного возраста, в том числе старше 50 лет. Несовершеннолетних — только с согласия родителей. Имена не записываем: только номер участника и возрастную группу (до 18, 18–49, 50+).
  2. Группы: нечётные номера участников — группа 1, чётные — группа 2.
    Группа 1: сначала набор A без подсказки, потом набор B с подсказкой.
    Группа 2: сначала набор B без подсказки, потом набор A с подсказкой.
    Так каждое сообщение проверяется и с подсказкой, и без, а разница между наборами не влияет на результат.
  3. Не подсказывайте и не обсуждайте ответы. После обоих листов можно рассказать правильные ответы — это тоже польза.
  4. Ответы перенесите в answers.csv (образец answers_TEMPLATE.csv): одна строка = один ответ на одно сообщение. Затем: python scripts/analyze_user_study.py docs/user_study/answers.csv
