# Исследование с людьми: помогает ли система?

Точность модели (94%) показывает, насколько хорошо **модель** отличает мошенничество. Но жюри важнее другое: **помогает ли система человеку** не попасться. Это проверяется только на людях.

## Что здесь

| Файл | Что это |
|---|---|
| `cards.pdf` / `cards.html` | Листы для печати: инструкция и согласие, наборы A и B без подсказки и с подсказкой системы |
| `messages.csv` | 20 сообщений, написанных для исследования (не входят в обучение): по 5 мошеннических и 5 обычных в каждом наборе, 7 на русском и 3 на казахском |
| `model_verdicts.csv` | Что модель сайта говорит о каждом сообщении. Это настоящие ответы модели, **включая 4 ошибки** (A6, B2, B8, B10: обычные сообщения названы подозрительными) |
| `answers_TEMPLATE.csv` | Образец, куда переносить ответы |

## Как провести (около 10 минут на человека)

1. Найдите 16–20 участников разного возраста, лучше несколько человек 50+. Несовершеннолетних приглашайте только с согласия родителей. Имена не записывайте.
2. Нечётные номера участников — группа 1: **A без подсказки → B с подсказкой**. Чётные — группа 2: **B без подсказки → A с подсказкой**.
3. Сначала дайте лист без подсказки, заберите его, потом дайте лист с подсказкой.
4. Перенесите ответы в `answers.csv`: одна строка = один ответ (`answer`: 1 = «да, мошенничество», 0 = «нет»; `confidence` от 1 до 5).
5. Запустите:

```bash
python scripts/analyze_user_study.py docs/user_study/answers.csv
```

Отчёт появится в `reports/user_study/REPORT_RU.md` с графиком.

## Что покажет отчёт

- Насколько чаще люди отвечают правильно с подсказкой, с доверительным интервалом и проверкой значимости (критерий Уилкоксона).
- Сколько мошеннических сообщений распознано и сколько обычных ошибочно приняты за мошенничество.
- **Чрезмерное доверие:** что происходит на четырёх сообщениях, где система ошиблась. Если с подсказкой люди там ошибаются чаще, это честный и важный вывод: объяснения причин важнее голого процента.
- Результаты по возрастным группам.

Перегенерировать листы после изменения модели: `python scripts/make_user_study.py`.
