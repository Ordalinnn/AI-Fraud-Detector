## 3. Изменения по слайдам (тексты на казахском, готовы к вставке)

### Слайд 4 · Зерттеу аппараты
В гипотезе заменить «нәтижелерін ережелер негізінде біріктірсек» на
**«нәтижелерін стекинг арқылы біріктірсек»**.
Строку «Тексеру тәсілі» оставить как есть.

### Слайд 5 · Деректер
Под «686 алаяқтық / 712 қауіпсіз» добавить строку:
**«+ 400 нақты SMS (UCI SMS Spam Collection) — модель шынайы хабарламалардың стилін де көруі үшін»**

### Слайд 6 · Жүйе қалай жұмыс істейді
- Заголовок: **«Бір модельге емес — бес модельге және олардың салмағын үйренетін стекингке сенеміз»**
- Перед карточкой «Мәтін → 20 белгі» добавить шаг: **«Маскировканы алу»** · «к0д → код, латын әріптері, көрінбейтін таңбалар»
- «20 белгі» → **«25 белгі»**
- В колонку моделей добавить пятую: **«Символдық n-грамдар + LR» · «сөз бөліктерінен: картаңыз / карту / карта»**
- Итоговая карточка: «Орташа ықтималдық + ереже бонусы / бонус ≤ 30%» →
  **«Стекинг» · «логистикалық регрессия әр модельдің салмағын деректерден үйренеді; ереже бонусы — 6-шы кіріс»**
- Нижняя строка: **«Қарапайым орташалауда үш әлсіз модель күштісін басып кететін еді. Стекинг салмақтарды өзі табады: символдық n-грам 1,68 · TF-IDF 1,43 · GB 0,40 · ережелер 0,29 · RF 0,23 · LR 0,10»**

### Слайд 7 · Логистикалық регрессия (пример на текущей модели)
- «Ертең сабақ болады» z = −2,0 → 0,12  →  **z = −2,97 → 0,05**
- точка на кривой: z = 2,81 → 0,94  →  **z = 3,14 → 0,96**
- **z = 0,05 + 1,79 + 1,22 + 1,18 − 1,10 ≈ 3,14**
- **0,05 — бос мүше w₀ · 1,79 — құпиялылық сөздері · 1,22 — мәтін ұзындығы · 1,18 — цифрлар саны · −1,10 — қалған белгілер**
- **σ(3,14) = 1 / (1 + 0,043) ≈ 0,96**
- **→ логистикалық регрессия бойынша алаяқтық ықтималдығы 96%**

### Слайд 9 · Ансамбль: есептеу мысалы → стекинг
Заголовок раздела: **«07 · СТЕКИНГ: ЕСЕПТЕУ МЫСАЛЫ»**. Сообщение то же:
«Ваша посылка задержана. Оплатите доставку 350 тг по ссылке kazpost-delivery.top»

| | Модель | pᵢ | logit pᵢ = ln(p/(1−p)) | салмақ wᵢ |
|---|---|---|---|---|
| M₁ | Логистикалық регрессия | 0,9998 | 8,33 | 0,10 |
| M₂ | Кездейсоқ орман | 0,480 | −0,08 | 0,23 |
| M₃ | Градиенттік бустинг | 0,555 | 0,22 | 0,40 |
| M₄ | TF-IDF + Байес | 0,811 | 1,45 | 1,43 |
| M₅ | Символдық n-грамдар | 0,974 | 3,63 | 1,68 |
| ΔR | Ережелік түзету (.top + kazpost) | 0,25 | — | 0,29 |

- **z = b + Σ wᵢ · logit(pᵢ) + w_R · ΔR**
- **z = 0,56 + 0,83 − 0,02 + 0,09 + 2,07 + 6,10 + 0,07 ≈ 9,71**
- **P = σ(9,71) ≈ 0,9999 → 99,9% → Критикалық**
- Строка внизу: **«Модельдер келіспесе (RF 0,48, GB 0,55), стекинг сенімдірек модельдерге көбірек салмақ береді. Ескі формула (қарапайым орташа) осы жерде 0,76 беретін еді»**
- Убрать строку «0,99 шегі…», вместо неё: **«Пайыз 99,9%-дан аспайды — жүйе ешқашан «100% сенімдімін» демейді»**

### Слайд 10 · Нәтижелер
- Крупно: **«42% → 93%»** (Recall: кілт сөз әдісі → біздің ансамбль)
- Подпись: **«Ансамбль кілт сөз іздеуге қарағанда алаяқтықтың 2 есе көбін ұстайды, ал жалған дабыл — 152-ден 6-ақ»**
- Таблица «ТӘУЕЛСІЗ ТЕСТ · 282 МЫСАЛ», колонки **Жаңа ансамбль · Жазбаша жұмыс · Кілт сөз**:

| | Жаңа ансамбль | Жазбаша жұмыс | Кілт сөз |
|---|---|---|---|
| Accuracy | **94,7%** | 82,3% | 69,5% |
| Precision | **95,3%** | 82,3% | 83,3% |
| Recall | **93,1%** | 78,5% | 42,3% |
| F1 | **94,2%** | 80,3% | 56,1% |
| ROC-AUC | **99,1%** | 93,0% | — |

- Сноска: **«Сол 282 хабарлама, бір сценарийдің нұсқалары тек бір жаққа түседі. 15 бөлініс бойынша орташа: 96,1% ± 1,4. Ең жақсы жалғыз модель (символдық n-грам) — 93,6%.»**

### НОВЫЙ слайд после «Нәтижелер» · «09 · ШЫНАЙЫ ӨМІРДЕ ТЕКСЕРУ»
Заголовок: **«Жюри ескертулерінен кейін: жүйені шынайы жағдайда тексердік»**.
Четыре карточки «было → стало» (как крупные числа на слайде 10):

1. **18,2% → 0,3%** · «2 242 нақты қарапайым SMS-тағы жалған дабыл (оқытуда болмаған)»
2. **73,6% → 88,4%** · «Қазақ тіліндегі дәлдік»
3. **46–83% → 93%** · «Жасырылған алаяқтық ұсталды: «к0д», латын әріптері, көрінбейтін таңбалар»
4. **8,2% → 0,7%** · «Калибрлеу қатесі (ECE): «80% қауіп» шынымен ~80% дегенді білдіреді»

Нижняя строка: **«Оқытуда мүлдем болмаған алаяқтық түрлері: 76,0% → 84,1% ұсталды»**

### Слайд 11 · Шатасу матрицасы (скрыт, но обновить)
TN **146** · FP **6** · FN **9** · TP **121**
- Accuracy = (121 + 146) / 282 = **94,7%**
- Precision = 121 / (121 + 6) = **95,3%**
- Recall = 121 / (121 + 9) = **93,1%**
- F1 = 2 · 0,953 · 0,931 / 1,884 = **94,2%**

### Слайд 12 · Қателерді талдау (скрыт, но обновить)
- 22 → **6** жалған оң, 28 → **9** жалған теріс
- Пример «Мама, телефоным сынып қалды…»: **P = 0,42 → Күдікті** было, теперь **P = 0,99 → Критикалық**
- Текст под примером: **«Бұрын 0,5 шегінен төмен еді. Символдық n-грам моделі мен стекинг қосылғаннан кейін бұл схема дұрыс танылады»**
- Қорытынды: **«Әлсіз жерлер енді: романтикалық (41%) және инвестициялық (66%) алаяқтықтың жаңа түрлері»**

### Слайд 13 · Түсіндірмелі AI
- «4 модель келіспесе…» → **«5 модель келіспесе, жүйе қолмен тексеруді ұсынады»**
- «Телефон мен браузер» → **«Сайт · кеңейтпе · Android»** · **«Кеңейтпе сайттағы модельдің өзін құрылғыда есептейді (4 552 мәтінде айырма < 10⁻⁹). Мәтін құрылғыдан шықпайды»**

## 4. Заметки докладчика (вставить в Speaker notes)

**1 · Нұрасыл · 0:20** — Құрметті қазылар алқасы, сәлеметсіздер ме! Біз — Тараз НЗМ-нің 12С сынып оқушылары Ордалин Нұрасыл мен Ғани Ақжол. Жобамыз — «AI Fraud Detector»: алаяқтық хабарламаны танып, оның ықтималдығын есептейтін математикалық модель.

**2 · Нұрасыл · 0:25** — Қазақстанда тіркелген қылмыстың 19,5%-ы — интернет-алаяқтық. Ең жиі үш схема: «картаңыз бұғатталды», «банк қызметкері» қоңырауы, жалған курьер мен ұтыс. Бәрінің ортақ белгісі — шұғылдық, код сұрау, сілтеме.

**3 · Нұрасыл · 0:20** — Мақсатымыз — хабарламаның алаяқтық болу ықтималдығын математикалық түрде бағалау. Ол үшін жеті міндет қойдық; негізгісі — бірнеше статистикалық модельді біріктіріп, нәтижені түсінікті ету.

**4 · Нұрасыл · 0:20** — Гипотезамыз: бірнеше әдісті стекинг арқылы біріктірсек, бағалау дәлірек әрі түсініктірек болады. Тексеру — тәуелсіз 282 хабарламада, кілт сөз әдісімен салыстыру. → Деректерге көшейік.

**5 · Нұрасыл · 0:25** — Үш тілде 1 398 хабарлама жинадық: 686 алаяқтық, 712 қауіпсіз, 24-тен астам схема. Жюри шынайы хабарламаларды сұрағандықтан, тағы 400 нақты SMS қостық. → Сөз Ақжолға.

**6 · Ақжол · 0:40** — Алдымен маскировканы алып тастаймыз: «к0д» → «код». Содан кейін 25 белгі есептеледі, бес модель бағалайды: үшеуі белгілер бойынша, екеуі — мәтіннен тікелей. Ең маңыздысы — стекинг: соңғы логистикалық регрессия әр модельге қаншалықты сену керегін деректерден өзі үйренеді. Ескі орташалауда үш әлсіз модель күшті модельді басып кететін еді.

**7 · Ақжол · 0:35** — Әр модельдің негізі — сигмоида. z — белгілердің салмақталған қосындысы, σ оны 0 мен 1 аралығындағы ықтималдыққа айналдырады. Мысалы, бұл хабарламада құпиялылық сөздері, ұзындық пен цифрлар z-ті 3,14-ке дейін көтереді, ықтималдық — 96%. «Ертең сабақ болады» — небәрі 5%.

**9 · Ақжол · 0:40** — Стекинг қалай есептейді: әр модельдің ықтималдығын логитке айналдырып, үйренген салмағына көбейтеміз. Мұнда RF мен GB екіұдай (0,48 және 0,55), бірақ стекинг сенімдірек мәтіндік модельдерге көбірек салмақ береді: z ≈ 9,7, P = 99,9%, критикалық қауіп. Ескі орташа формула осы жерде небәрі 0,76 беретін еді.
